General Information

This interface allows you to simulate the virus spread at D+3 based on the data you provide. Adjust the sliders to reflect your real situation (cases, deaths, recoveries...). The chart below will display:

  • On the left: the number of cases currently entered
  • On the right: the AI-predicted number of cases in 3 days

More information about the AI

How does this AI work?

This prediction system uses a Random Forest regression algorithm trained on historical COVID data.

  • It takes into account 8 variables (new cases, deaths, recoveries, 3-day averages, growth...)
  • The data is normalized to standardize the scales
  • The prediction represents an estimate of the number of cases in 3 days
  • The model achieves an R² score above 0.91, ensuring high reliability

The model was evaluated on a test set and shows the following performance:

  • R²: 0.917 (91.7% of the variance explained)
  • MAE: 1594.14
  • RMSE: 1736.43
